# Code of Conduct

## Our standard

This project is a specification and the conversation around it. People who take part, in issues, pull requests, discussions and reviews, are expected to:

- argue about the text, not about the person;
- bring evidence where evidence exists, and say plainly when it does not;
- accept that a rejected proposal is a decision about the text, not about its author;
- keep other people's confidential material confidential, including the organizations behind anonymized Reference Cases.

The following are not acceptable anywhere in this project: personal attacks, harassment, publishing someone's private information, sexualized language or imagery, and sustained disruption of a discussion after being asked to stop.

## Scope

This code applies in every space this project runs: the repository, its issues, pull requests, wiki and discussions, and any place where someone represents the project publicly.

## Enforcement

The maintainer is responsible for clarifying and enforcing this code, and may remove, edit or reject contributions that do not follow it, and may restrict or ban participation for behaviour that is repeated or severe.

To report a problem, open an issue addressed to the maintainer. If the report should not be public, say so in a minimal issue and the maintainer will move it to a private channel before any detail is discussed. Reports are handled promptly and, where a private channel is used, confidentially.
